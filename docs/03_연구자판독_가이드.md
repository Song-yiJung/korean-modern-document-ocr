# STEP 3: 연구자 판독 및 최종 검증

**이 문서는 본 파이프라인의 핵심입니다.**

STEP 1(Vision)과 STEP 2(Gemini)는 **도구**일 뿐, 최종 산출물은 **연구자의 전문적 판독**입니다.

---

## 📋 개요

| 단계 | 담당 | 입력 | 출력 | 소요 시간 |
|------|------|------|------|---------|
| STEP 1 | AI (Vision) | 이미지 | vision_raw | 장당 1-3초 |
| STEP 2 | AI (Gemini) | vision_raw + 이미지 | gemini_corrected | 장당 30초 |
| **STEP 3** | **인간 (연구자)** | **gemini_corrected + 이미지** | **researcher_final** | **장당 5-15분** |

---

## 🔍 AI 자동화의 한계

### 1. 맥락 이해 부족
- **Vision/Gemini:** 물리적 글자 형태만 인식
- **연구자:** 문서의 역사적·행정적 맥락 이해
  - 예: "불국사 관련 서신" = 문화재 지정 과정 해석

### 2. 구자체·필기체 변이자
- **Gemini:** 유사 글자 혼동 가능 (臺/台, 螭/龜 등)
- **연구자:** 문맥 + 시대 용례로 정확 판독

### 3. 역사적 고유명사
- **AI:** 인명·지명 표준화 불가
- **연구자:** 당대 기록과 비교해 정확한 표기 확인
  - 예: 藤島亥治郞 vs 藤岡亥治郞

### 4. 행정 문서 구조
- **AI:** 표 레이아웃 추정만 가능
- **연구자:** 조선 행정계층(郡/面/里) 구조 이해로 결손 감지

### 5. 인장·부기·낙서
- **AI:** 인장 위치만 표기 가능
- **연구자:** 관인 종류, 승인 경로, 관직 변화 읽기

## 📝 판독 절차

### Phase 1: 초기 정독 (각 문서 5-10분)

**1단계: Gemini 결과 정독**

視覚障害者向け読み上げツール使用 또는
구두로 천천히 읽으며 문제 지점 표시

**2단계: 원본 이미지 대조**
문맥상 어색한 부분 → 원본 이미지 확인
글자 모양이 모호한 구간 → 이미지에서 직접 판독
누락·오판 가능성 지점 → 마킹

**3단계: 메모 작성**

{파일ID}_notes.txt 생성:
라인 5: "國" vs "国" 불확실 (이미지 확인 필요)
라인 12-14: 인명 "藤島亥治郞" 맞나? (기록 검증)
라인 18: "〃" 사용 여부 (선행 행의 지명과 동일한지 확인)
라인 25: "(판독불가)" 앞 글자 이미지로 재판독 시도

---

### Phase 2: 지식 기반 수정 (각 문서 5-15분)

**1. 인명·지명 표준화**

❌ gemini_corrected:
藤岡亥治郞가視察を行った
✅ researcher_final:
藤島亥治郞[*1]が視察を行った
[*1]: 당시 조선총독부 고적조사위원회 위원.
《朝鮮の文化遺産》(1933) 저자.

**2. 표 구조 검증**

❌ gemini_corrected:
郡   面     里名
慶州 內東   馬洞
慶州 陽北   凡谷   ← 중복 축약 누락
✅ researcher_final:
郡   面     里名
慶州 內東   馬洞
〃   陽北   凡谷   ← 〃로 상위 계층 표시

**3. 도메인 어휘 확인**

불국사·미술사 용어 오독 체크

阿彌陀如來 vs 阿彌陀佛 (선정 대상)
舍利塔 vs 舍利堂 (불교건축 용어)
白雲橋 vs 白雲門 (불국사 교량 이름)

**4. 환각 감지 및 표기**

❌ gemini_corrected가 원본에 없는 내용 추가:
「昭和5年3月15日、不国寺の修復工事が完了した」
✅ researcher_final:
원본 이미지에 확인 안 됨 → 삭제 또는
「[원본 불명확] 불국사 수리 관련 기록」으로 표기

## ✅ 체크리스트

각 문서마다 다음을 확인하세요:

### 1단계: 이미지 대조

- [ ] gemini_corrected의 각 문단이 이미지와 일치하나?
- [ ] 누락된 텍스트가 있나? (특히 인장 주변)
- [ ] 세로쓰기 흐름이 올바르게 배열되었나?

### 2단계: 맥락 검증

- [ ] 인명이 역사 자료와 일치하나? (철자 포함)
- [ ] 지명이 당시 행정 구역과 일치하나?
- [ ] 날짜 연호(昭和 N년)가 그레고리력으로 올바르나?
- [ ] 전문 용어(불교·미술사)가 정확한가?

### 3단계: 표 구조

- [ ] 행정 계층이 누락되지 않았나? (〃 사용 확인)
- [ ] 열 간 공백이 원본과 일치하나?
- [ ] 중복 축약이 일관적인가?

### 4단계: 환각

- [ ] 원본에 없는 내용이 추가되지 않았나?
- [ ] 판독 불가 부분이 [?] 또는 □로 표기되었나?

### 정확도 측정 (전체 중 일부 샘플)

```python
# sample 10% 에 대해:
# 1. 정답지(reference) 직접 작성
# 2. 자동 도구로 edit distance 계산

edit_distance = levenshtein_distance(gemini_corrected, reference)
accuracy = 100 * (1 - edit_distance / len(reference))
```

**기대값:**
- Vision 평균: 87-90%
- Gemini 평균: 93-96%
