1. 좌측 메뉴 → "APIs & Services" → "라이브러리"
2. 검색: `Vision`
3. `Cloud Vision API` 클릭 → "활성화"

### 1.3 서비스 계정 키 생성

1. 좌측 메뉴 → "APIs & Services" → "사용자 인증 정보"

3. 서비스 계정 세부정보 입력:
   - 계정 이름: `vision-ocr-account`
   - 계정 ID: 자동 생성
4. "만들고 계속" → 역할 선택
   - `Editor` 선택
5. "만들고 계속" → (열쇠 단계 건너뛰기)

### 1.4 키 다운로드

1. 생성된 서비스 계정 클릭
2. "열쇠" 탭 → "열쇠 추가" → "새 열쇠 만들기"

## 🚨 보안 주의

### API 키 관리
✅ DO:

.env 파일은 .gitignore에 등록 (git 커밋 금지)
키는 파일/Secret으로 관리 (하드코딩 금지)
주기적으로 키 로테이션
사용하지 않는 프로젝트는 API 비활성화

❌ DON'T:

키를 소스 코드에 직접 입력
키를 공개 저장소(GitHub)에 올리기
키를 이메일/메시지로 전송
타인과 키 공유


### 비용 통제
Vision API:

월 1,000장 무료 (초과 시 장당 ~₩2)
프로젝트별 청구 한도 설정 권장

Gemini API:

무료: 분당 10호출 (RPM)
유료: 분당 1,000호출
프로젝트별 청구 한도 설정 권장


**BigQuery 청구 모니터링:**
Google Cloud Console → 청구 → 예산 및 알림
→ 월 예산 설정 (예: $10 USD)

## 📞 트러블슈팅

### Q. "Keyfile not found" 에러
원인: VISION_KEY_PATH 경로 오류
해결:

ls -la /path/to/vision_key.json 으로 파일 존재 확인
절대 경로 사용 (상대 경로 X)
경로에 공백/특수문자 없는지 확인


### Q. "401 Unauthorized" (Gemini)
원인: GEMINI_API_KEY 오류
해결:

AIzaSy...로 시작하는지 확인
공백 없이 전체 복사했는지 확인
AI Studio에서 새 키 생성


### Q. "Quota exceeded" (429 에러)
원인: RPM 초과
해결:

무료: sleep_interval을 6초 → 10초로 증가
유료: API에 업그레이드 신청
--sleep 인자로 조정: python step2_gemini.py --sleep 10
